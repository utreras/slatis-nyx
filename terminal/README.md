# Terminal colour schemes

The 16 ANSI colours from each theme variant, projected onto the formats their
emulators read. Generated by `npm run build:terminal`, so the palette stays in
sync with the editor.

| Emulator | Folder | Install |
|---|---|---|
| iTerm2 | `itermcolors/` | Settings → Profiles → Colors → Color Presets → Import |
| Ghostty | `ghostty/` | Copy into `~/.config/ghostty/themes/`, then `theme = slatis-nyx` |
| Alacritty | `toml/` | `import = ["~/.config/alacritty/slatis-nyx.toml"]` |
| Kitty | `conf/` | `include slatis-nyx.conf` in `kitty.conf` |
| Warp | `yaml/` | Copy into `~/.warp/themes/` |
| Windows Terminal | `json/` | Paste the object into the `schemes` array in `settings.json` |

The accessibility variants carry through. In Deuteranopia, ANSI green resolves
to blue and ANSI red to amber, so `git diff` and test output stay readable in the
terminal for the same eyes the editor variant was built for.
